# QUBE-Servo 3 — 阻抗控制  v3

實驗室專題：以位置內迴路阻抗控制實現 QUBE-Servo 3 旋臂的柔順互動。

---

## 專案目標

傳統 PID 控制只能追蹤目標位置，無法描述系統與外部接觸的「柔順性」。  
本專題實作阻抗控制，讓旋臂能像虛擬彈簧-阻尼系統一樣回應外力：

```
M · θ'' + B · θ' + K · θ = F_ext
```

透過調整 **K（剛性）**、**B（阻尼）**、**M（虛擬慣量）** 三個參數，  
可以改變旋臂對外力的回應特性，而不需要更換實體機構。

---

## 安裝

```bash
pip install -r requirements.txt
```

> **注意**：QUBE-Servo 3 硬體驅動（`pal` 套件）需另行安裝，請參考 Quanser 文件。

## 執行

```bash
python main.py
```

---

## 使用說明

1. 確認 QUBE-Servo 3 已連接並開機
2. 執行 `python main.py`
3. 調整左欄的阻抗參數（K / B / M）和 PD 增益（Kp / Kd）
4. 設定實驗時長和次數
5. 按「▶ 開始實驗」
6. 實驗完成後按「⬇ 儲存 Excel」匯出資料

---

## 控制參數說明

| 參數 | 意義 | 單位 | 預設值 |
|------|------|------|--------|
| K | 虛擬剛性（越大越硬，越小越軟） | N·m/rad | 1.0 |
| B | 虛擬阻尼（越大收斂越快，過小會振盪） | N·m·s/rad | 0.1 |
| M | 虛擬慣量（越大對衝擊反應越慢） | kg·m² | 0.05 |
| Kp | 內迴路比例增益 | — | 20.0 |
| Kd | 內迴路微分增益 | — | 0.5 |
| θ_d | 目標角度 | rad | 0.0 |

**穩定條件**：B² ≥ 4MK（臨界阻尼），GUI 會自動提示是否欠阻尼。

## 外力估算原理

不使用額外的力感測器，透過電流估算外力扭矩：

```
τ_ext = Kt × I − (J × α + Bf × ω)
```

- `Kt × I`：馬達輸出扭矩
- `J × α`：慣性扭矩
- `Bf × ω`：摩擦扭矩
- `τ_ext`：估算的外部力矩

精度受到 Kt、J、Bf 辨識準確度的影響。

## 安全機制

| 項目 | 限制值 | 觸發後果 |
|------|--------|---------|
| 角度 | ±270° | 緊急停止 |
| 速度 | ±50 rad/s | 緊急停止 |
| 電流 | >4.0 A | 緊急停止 |
| 外力估算 | >1.0 N·m | 本週期外力歸零（不停止） |
| 暖機期 | 前 50 個週期（100ms） | 電流/外力檢查暫停 |

## 馬達參數修改

所有硬體常數集中在 `config.py`，系統辨識後直接修改即可：

```python
Kt         = 0.042      # 力矩常數   [N·m/A]
J_motor    = 4.0e-6    # 轉子慣量   [kg·m²]
B_friction = 1.0e-5    # 黏性摩擦   [N·m·s/rad]
```
